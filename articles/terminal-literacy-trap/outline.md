# Outline

Optional and deliberately lightweight — bullets are fine. Its job is to expose a weak argument
before the prose hides it.

## Argument in one sentence

Advocating for "terminal literacy" as the path to AI-powered knowledge work is a category error —
the real answer is that AI tools will abstract the terminal away, not that users will come to it.

## Objections to address

The counterarguments the idea file lists:

1. **"Power users will always prefer CLI"** — true, but irrelevant. The question isn't what power
   users prefer, it's how knowledge workers will access AI tools. The 99% matter more than the 1%.
2. **"Terminal is actually simple once you learn it"** — survivorship bias. The people saying this
   made it through; the 50% who dropped out aren't writing Medium posts.
3. **"Claude Code's natural language interface makes CLI accessible"** — partially true, but you
   still need npm/pip installation, path navigation, and an understanding of what "files" and
   "directories" mean in a terminal context. The natural language is one layer; the environment is
   another.
4. **"GUIs are dumbed down / less powerful"** — false dichotomy. The right answer is GUIs that
   expose power progressively; Cursor proves this is possible.
